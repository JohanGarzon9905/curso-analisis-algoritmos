# Curso de Análisis de Algoritmos

Repositorio oficial para el almacenamiento de actividades prácticas, ejercicios y laboratorios.

## Estructura del Repositorio

* **`laboratorios/`**: Informes de laboratorio evaluativos.
* **`ejercicios-clase/`**: Código de las sesiones prácticas y ejercicios de Python.
* **`benchmarks/`**: Scripts de medición de tiempos y graficación.
